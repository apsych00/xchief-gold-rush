Decisions (do not redesign):
1. `server/alerts.js` gains a Telegram transport next to the webhook one: when `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID` are set, every alert is also posted with `sendMessage` (`parse_mode: 'HTML'`, `disable_web_page_preview: true`); failures are logged, never retried, never crash. 2. One event catalogue in `server/alerts.js`, exported, each with a code, a severity (`info`, `warn`, `critical`), a one-line message and a one-line recommendation (empty when no action is needed). Message format: `<b>[severity] Gold Rush</b>\n<message>\n<i>Do:</i> <recommendation>`.
3. Wire the producers: safemode level change, limits block list non-empty/cleared (replace the existing alerts line), coupon pool checks in the existing 60 s kiosk sweep, deploy scripts. Throttle stays as it is (one per condition per 5 minutes, recovery resets).
